# AI vs ML vs Deep Learning

## Project Description

This project provides a simple comparison of Artificial Intelligence (AI),
Machine Learning (ML), and Deep Learning (DL).

It explains their definitions, differences, relationship, and real-world
applications in an easy-to-understand way.

## Objective

The objective of this project is to build a clear understanding of the
relationship between Artificial Intelligence, Machine Learning, and Deep
Learning.

## Relationship

Deep Learning is a subset of Machine Learning, and Machine Learning is a
subset of Artificial Intelligence.

AI
└── Machine Learning
    └── Deep Learning

Therefore:

Deep Learning ⊂ Machine Learning ⊂ Artificial Intelligence

## Comparison

| Feature | AI | Machine Learning | Deep Learning |
|---|---|---|---|
| Scope | Broadest field | Subset of AI | Subset of ML |
| Main Purpose | Perform intelligent tasks | Learn patterns from data | Learn complex patterns using neural networks |
| Data Requirement | Varies | Usually requires data | Usually requires large amounts of data |
| Examples | Virtual assistants, expert systems | Recommendation systems, spam detection | Image recognition, speech recognition |
